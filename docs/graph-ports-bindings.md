# 端口、绑定与控制信号

> 本文档定义节点端口的两类绑定语义,以及"真正的信号"——控制信号。
> 相关文档:[图运行时总纲](./graph-runtime-overview.md) · [执行模型](./graph-execution-model.md) · [节点类型](./graph-node-types.md)

## 1. 核心命题

> **连线 = 数据流动与触发方向(推);内嵌绑定 = 开火时读取的对象(拉)。两种机制,不互相污染。**

## 2. 端口双绑定模型

端口除了连线,还有**内嵌绑定**——声明在接口上、编辑器可见,但不构成"流":

| 端口 | 绑定种类 | 语义 |
|------|---------|------|
| 输入 | 连线 | 参与就绪等待;上游输出满足/唤醒该端口 |
| 输入 | 默认常量 | 即时满足,值为常量;不参与就绪等待 |
| 输入 | 全局读取 | 即时满足,**开火时取全局变量最新值**;不参与就绪等待 |
| 输出 | 连线 | 每轮必发(可 None),推给下游 |
| 输出 | 全局写入 | 每轮开火时写入命名的全局变量 |

本节描述**数据端口**;控制端口的绑定与默认电平见 §4。

**就绪规则**:只有未屏蔽的**连线**数据输入参与"等待所有输入"(见 [执行模型](./graph-execution-model.md) §2.3);引用与常量端口从第 0 轮起即时满足。

无连线、无默认、无引用的**裸端口** → 编辑事务校验报错(强迫显式;可显式声明默认 None)。

## 3. 为什么全局变量不是输出源

全局变量是**状态**,不是输出。它被读取时不产生输出、不唤醒下游:

- 全局被改 → 没有任何节点被触发;
- 读取它的节点在**下一次因其他原因开火时**才看到新值;
- 读取是拉,不是推——全局写入不进入传播,不会产生输入污染。

## 4. 控制信号:与数据严格分离的独立通道

控制信号与数据是**完全不同的两类通道**,端口层强制区分:

| | 数据通道 | 控制通道 |
|---|---|---|
| 端口 | data-in / data-out | control-in / control-out |
| 载荷 | 任意 Python 对象(类型鸭子) | **无载荷,只承载电平**(active / inactive) |
| 连线 | data-out → data-in | control-out → control-in |
| 采样保持 | 是 | 是(电平按轮保持) |

- **交叉连线校验报错**:数据不能流入控制端口,控制信号不能流入数据端口——图层面不允许直连;
- **转换必须经由节点内部**:数据转控制(如比较器:数据入、控制出)或控制转数据(如条件选择)是节点黑盒内部的职责,端口层不混。

### 4.1 控制端口的语义由声明决定

控制信号不携带"含义",含义由**端口声明**决定:

| 声明 | 语义 |
|------|------|
| control-in:门控(enable) | 电平 active = 门开;inactive = 跳过昂贵内部工作(不调 LLM),数据输出照发 None |
| control-in:屏蔽(mask:目标数据端口) | 电平 active = 该数据端口本轮被忽略:屏蔽输入不参与就绪与计算(旁路语义);屏蔽输出不发值,下游保持旧值 |
| control-out | 声明其含义(如时钟节点的方波电平输出) |

### 4.2 默认电平与保持

- 控制端口不连线 → 其**声明的默认电平**生效(类型定义时声明;缺省:门控 = 常开,屏蔽 = 常闭);
- 连线的控制端口:收到第一个电平前用默认电平,此后采样保持最近电平;
- **控制端口不参与数据端口的就绪等待**——电平永远有定义,不存在 warm 问题;
- 屏蔽只作用于数据端口;控制端口不可被屏蔽(断开连线即等效,无需屏蔽机制)。

### 4.3 边界情况

- **全部数据输入被屏蔽**(门开时)→ 节点退化为源节点,每轮自发触发。无需特判——控制信号可以把转换节点临时"解耦"成源;
- **屏蔽 ≠ None**:None 是"节点主动报告无事发生",屏蔽是"输出暂停、下游冻结在旧值"。多数下游对两者反应相同;需要感知新鲜度的节点看数据包时间戳即可区分;
- **费用闸门有两个层次**:控制信号(外部决定能不能开火)+ 节点自身判定(看到数据决定改不改变)。绝大多数轮次里 LLM 节点不产生任何调用费用。

## 5. 可编排的控制模式

- 旁路某段数据处理:屏蔽其输入,节点按部分数据工作;
- 暂停一条链:屏蔽链上某输出,下游冻结在旧值,世界其他部分继续转;
- 给反馈环调速:用方波信号周期性屏蔽反馈边;
- 临时解耦:屏蔽全部输入,节点变为自发源。

全部是连线,不是新原语。

## 6. 校验相关

- 端口绑定合法性:裸数据端口报错;绑定必须指向已声明资产;
- 连线 kind 匹配:data→data、control→control,**交叉连线报错**;
- 引用存在性:绑定引用的全局变量/常量必须已声明,否则提交校验抛异常(见 [资产系统](./graph-assets.md));
- 完整校验清单见 [持久化与编辑](./graph-persistence-and-editing.md) §5。
