# 执行模型:同步轮次与信号传播

> 本文档记录引擎执行语义的**最终决策**:同步轮次、采样保持、轮初读轮末提交。
> 相关文档:[图运行时总纲](./graph-runtime-overview.md) · [端口、绑定与控制信号](./graph-ports-bindings.md) · [持久化与编辑](./graph-persistence-and-editing.md)

## 1. 核心命题

> **引擎是一个常驻热运行的数据流网络,以同步轮次推进:每一拍,所有节点基于轮初值计算,轮末统一交换。**

执行模型属于同步响应式数据流范式(Lustre / Esterel / Simulink 一族):每个轮次每个节点都产出值,值可缺省(None),时钟只是数据流的一种。该范式提供确定性与可静态分析的成熟理论。被否方案见 §8。

## 2. 同步轮次

```
tick → 轮初:所有节点读取端口与全局变量的当前值
     → 轮内:各节点独立计算(顺序无关)
     → 轮末:所有输出值、全局写入统一交换
     → tick+1
```

### 2.1 采样保持

每个端口**保持最近收到的值**。慢速源只是更新得慢,端口上永远有确定的值(可能是旧的)——没有"值丢失"或"等待下一次"的歧义。

### 2.2 轮初读、轮末提交

- 所有节点基于**轮初**的值计算,产出在**轮末**统一交换;
- **节点执行顺序无关紧要**——调度器、校验器、未来并行执行都自由,不存在"声明顺序影响结果"的隐性依赖;
- 反馈环天然正确:环内值一拍一拍传播,不会轮内级联;
- 代价只有一个:下游看到上游变化有**一轮延迟**,对世界模拟无感(世界拍子本来就慢)。

### 2.3 就绪规则

节点就绪(开始每轮触发)当且仅当:**所有未屏蔽的连线数据输入端口都至少收到过一个值(warm)**。

- 引用与常量绑定的数据端口即时满足,不参与等待(见 [端口、绑定与控制信号](./graph-ports-bindings.md));
- 控制端口不参与就绪等待——电平永远有定义(默认电平或最近收到的电平);
- 就绪前的节点每轮不触发、不发输出;就绪后每轮触发;
- 全部数据输入被屏蔽(门开时)的节点退化为源节点,每轮自发触发——这是就绪条件的自然结果,无需特判。

## 3. 输出契约

- **未屏蔽的数据输出端口每轮必发一个值,可发 None**(控制输出按轮保持电平,见 [端口、绑定与控制信号](./graph-ports-bindings.md) §4);
- None 是"节点主动报告无事发生",不是错误;
- 强制每轮必发(即使 None)的原因:**让链路完全显式**——下游永远可以判定"本轮所有输入都已到达",不存在"某些输入来了没有"的随机性。

## 4. 数据包(数据通道)

数据包是沿数据连线流动的**不可变数据包**:

| 字段 | 含义 |
|------|------|
| 载荷(payload) | Python 对象,任意类型 |
| 来源 | 产生它的节点/端口 |
| 时间戳 | 产生轮次,供新鲜度判定 |

- 扇出 = 复制:一条输出连向多个输入,每个输入收到同一份数据;
- 数据通道与控制通道**严格分离**:控制信号无载荷、只承载电平,是独立通道(见 [端口、绑定与控制信号](./graph-ports-bindings.md) §4)。

## 5. 多速率

不同源以不同频率发值(时钟每秒、情绪每 tick、用户消息不定时),下游无需适配——采样保持下,每个端口读到的永远是最近值。速率适配器(采样、保持、去重)是可选的普通节点,不是系统机制。

## 6. 循环与执行器保底

- **拓扑不禁止循环**:死循环、纯反馈环都是合法的用户设计——是否出现循环是编辑状态决定的,只要合适,循环就是有用的;
- **执行器只保底不挂起**:轮次步进保证任何环都是"每轮转一圈",成本是若干程序节点的判断,不构成挂死;
- 编辑器提供静态提示(无源环永不自发触发;无门控环每轮空转),提示不是禁止。

## 7. 节点异常策略

"任意输入都可以流进来"意味着节点一定会遇到处理不了的输入,世界不能因单节点异常而停:

1. 节点异常 → 捕获 → 本轮所有输出发 None + 一条错误事件进日志(编辑器可见);
2. 连续 N 轮异常 → **熔断**:跳过内部工作、照发 None、告警,防止坏节点每轮烧资源;
3. 世界不停,其他链路照常;
4. LLM 调用失败沿用既有文档的错误回滚思想,由节点内部的工具循环处理。

## 8. 被否定的方案

- ❌ **令牌队列 join**(每个输入消费一个令牌、以最慢输入为节奏):引入队列堆积、丢弃策略、背压三个新问题;采样保持一个都没有。
- ❌ **零延迟级联传播**:反馈环导致轮内级联直至挂起;轮次步进解决。
- ❌ **共享黑板**:数据写入的消费时机不确定;数据随信号流动则路由与消费时机由解释器语义确定。
- ❌ **运行时类型强制**:类型注解只做编辑期静态检查,运行时鸭子类型(见 [节点类型](./graph-node-types.md) §5)。
